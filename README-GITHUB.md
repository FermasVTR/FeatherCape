# FeatherCape — GitHub Actions build

Fabric 1.21.11 / Java 21.

## Как получить JAR

1. Создай новый **public** репозиторий на GitHub.
2. Загрузите **все файлы и папки из этого проекта** в репозиторий (не загружай сам ZIP внутрь проекта).
3. Открой вкладку **Actions**.
4. Выбери **Build FeatherCape**.
5. Нажми **Run workflow**.
6. После окончания зелёного `Build` открой этот запуск.
7. Внизу страницы скачай артефакт **FeatherCape-jars**.
8. Внутри будет JAR из `build/libs`.

## Важно

Этот репозиторий содержит текущий исходник FeatherCape. GitHub Actions только собирает его; он не исправляет ошибки исходника автоматически.

Для Minecraft 1.21.11 проект использует Java 21, Fabric Loader 0.18.4, Yarn 1.21.11+build.4 и Fabric API 0.141.4+1.21.11.
